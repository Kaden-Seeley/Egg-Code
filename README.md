# EggCode

EggCode is a simple desktop timer designed to help you stay focused while coding. The interface is built with HTML, CSS, and JavaScript and runs as an Electron application.

## Requirements

To run the source code, you need:

- [Node.js](https://nodejs.org/) and npm
- A desktop operating system supported by Electron
- The source code from this repository

## Setup

Clone the repository, open a terminal in the project folder, and install the dependencies:

```bash
npm install
```

## Run From Source

Start EggCode in development mode with:

```bash
npm start
```

## Build

To create a Windows portable build locally, run:

```bash
npm run build
```

Build output is written to the `dist/` folder and is excluded from version control.

## Installer

An official installer is coming soon. Until then, you can run the application from source or create a local portable build using the command above.
